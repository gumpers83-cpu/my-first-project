# My First Project

Мой первый проект — одностраничное веб-приложение для работы со шторами: замеры, расчёт ткани, смета.

## Что умеет приложение

- **Замеры** — ввод размеров окон, автоматический расчёт рекомендуемого карниза и высоты шторы.
- **Расчёт ткани** — расчёт ширины/высоты, количества полотен, метража, учёт раппорта.
- **Балкон и панорама** — расчёт по секциям.
- **Римские, рулонные, жалюзи** — отдельный расчёт изделий.
- **Смета** — подсчёт стоимости ткани, подкладки, фурнитуры и пошива.
- **Описания и фото** — привязка фото и заметок к окнам.
- **Экспорт** — CSV, JSON-проект, печать, скачивание HTML.

## Как запустить

1. Откройте файл `index.html` в браузере (двойной клик или «Открыть с помощью»).
2. Вносите данные в жёлтые поля — зелёные значения считаются автоматически.
3. Данные сохраняются в браузере (`localStorage`). Для переноса на другое устройство используйте «Сохранить проект» (JSON).
